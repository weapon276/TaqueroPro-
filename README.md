## 📱 ¿Qué es TaqueroPro?

**TaqueroPro** es una aplicación web progresiva (PWA) diseñada **específicamente para negocios de tacos**. Te ayuda a controlar costos, inventario, ventas y ganancias desde tu celular, **incluso sin internet**.

### 🎯 Hecho para taqueros, por desarrolladores que aman los tacos

---

## ✨ Características principales

| Módulo | Funcionalidad |
|--------|----------------|
| 🌮 **Calculadora de precios** | Calcula costo real por taco (carne, tortilla, verdura, salsa) |
| 💰 **Sugerencia inteligente** | Te recomienda precio de venta según % de ganancia y tu zona |
| 📊 **Control de gastos** | Registra: insumos, servicios, renta, gasolina, personal |
| 💵 **Registro de ventas** | Diferencia entre efectivo y tarjeta (con comisión automática) |
| 📦 **Inventario premium** | Controla stock, alertas de productos bajos, fechas de compra |
| 📈 **Reportes automáticos** | Diarios, semanales, mensuales y anuales |
| 🎨 **Personalizable** | Cambia el nombre de tu negocio en la app |
| 🔔 **Notificaciones** | Te avisa cuando el inventario está bajo |
